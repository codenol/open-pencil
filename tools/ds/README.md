# Инструменты работы с файлами дизайн-системы

Скрипты правят `.fig` напрямую: распаковывают контейнер, меняют граф,
собирают обратно. Формат — ZIP с `canvas.fig` внутри (киви-заголовок `fig-kiwi`).

## Важно перед запуском

Пути импортов в новых скриптах ведут на пакеты воркспейса. У части старых
скриптов путь всё ещё смотрит в `/opt/open-pencil-clean/packages/*/dist/` —
если репозиторий лежит в другом месте, поправьте путь в начале файла.

## Скрипты

| Скрипт | Что делает |
|---|---|
| `build-graph-json.mjs` | строит данные для графа связей (узлы + рёбра) |
| `build-link-graph.mjs` | подробная карта: состав компонентов и их связи |
| `relink-group.mjs` | связывает одну группу разорванных инстансов с мастером |
| `relink-all.mjs` | связывает всё, что можно связать по имени |
| `link-icons.mjs` | инстансы иконки → мастер-компонент иконки |
| `link-icon-instances.mjs` | все инстансы с именем → вариант нужного размера |
| `link-all-icons.mjs` | досвязывает иконки, ориентируясь на окружение |
| `link-breadcrumbs.mjs` | связки на странице breadcrumbs (tab + иконки) |
| `link-button-icon-action.mjs` | иконки внутри `button-icon-action` по размерам |
| `component-rules.mjs` | пишет правила мастеров (назначение, когда брать, запреты, проверки) в `pluginData` |
| `mark-default-variants.mjs` | помечает осмысленный базовый вариант у наборов вариантов |
| `table-cell-width.mjs` | делает ширину ячеек таблицы тянущейся по колонке |
| `import-tokens.mjs` | импортирует экспорт Figma Variables (Dark/Light) в переменные документа: коллекция палитры, коллекция с режимами и ссылки между ними; `--verify=<файл.fig>` сверяет записанное с исходными токенами |

## Грабли

- **Не упаковывайте результат экспорта повторно.** `exportFigFile` возвращает
  готовый ZIP. Если записать его как `canvas.fig` и упаковать снова — файл
  не откроется: «Invalid fig-kiwi container».
- **Отключите исходный архив перед экспортом** — иначе экспорт вернёт файл
  как есть, игнорируя правки: `releaseOriginalFigArchive(graph)`.
- **У инстанса детей в файле нет** — так задумано, как в Figma. Инстанс хранит
  только ссылку на мастер; содержимое подтягивается при открытии.
